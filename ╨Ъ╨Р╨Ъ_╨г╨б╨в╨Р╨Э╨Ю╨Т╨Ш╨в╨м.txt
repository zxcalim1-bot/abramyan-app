ПОМОЩНИК «АБРАМЯН + PYTHON» ДЛЯ GALAXY WATCH — работает без интернета

1. СОБРАТЬ APK (на компьютере, один раз нужен интернет)
   - Установи Android Studio: https://developer.android.com/studio
   - Распакуй этот архив. В Android Studio: File -> Open -> выбери папку abramyan-watch.
   - Подожди, пока закончится синхронизация (внизу полоска загрузки).
   - Меню Build -> пункт сборки APK (Build APK / Generate APKs).
   - Готовый файл: app/build/outputs/apk/debug/app-debug.apk

2. ВКЛЮЧИТЬ ОТЛАДКУ НА ЧАСАХ
   - Часы и компьютер должны быть в одной сети Wi-Fi.
   - Настройки -> О часах -> Программное обеспечение -> 5 раз нажми «Версия ПО».
   - Появится пункт «Параметры разработчика»: включи «Отладка ADB» и «Беспроводная отладка».
   - В «Беспроводная отладка» нажми «Подключить новое устройство» (Pair new device):
     на экране будут IP-адрес:порт и 6-значный код.

3. УСТАНОВИТЬ НА ЧАСЫ
   В Android Studio внизу открой вкладку Terminal и введи по очереди:
     adb pair IP:ПОРТ КОД
     adb connect IP:ПОРТ          (порт с экрана «Беспроводная отладка», он другой)
     adb install app/build/outputs/apk/debug/app-debug.apk

   Если пишет, что adb не найден, на Windows используй полный путь:
     %LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe

   Если часы теряют Wi-Fi рядом с телефоном, временно выключи на часах Bluetooth.

КАК ПОЛЬЗОВАТЬСЯ
   Поиск сверху: пиши по-русски или английскими буквами (summa cifr, perimetr, array87,
   oshibka indexerror, sortirovka). Находит задачи Абрамяна и темы справочника Python.
   Пустой поиск — список групп и кнопка «Справочник Python».
   Группа -> номер задачи -> решение. Крутить список можно пальцем или безелем.
   «‹» и «›» — соседние задачи, A− / A+ — размер шрифта, кнопка «Назад» на часах — шаг назад.
